# SideNote · 便签待办

Windows 原生桌面应用，使用系统自带的 .NET Framework / WPF，无需下载依赖。

## 启动

双击 `SideNote.exe`。右侧屏幕中段约 50% 的区域支持触边展开；也可点击系统托盘图标打开。首次打开后，鼠标离开窗口会自动收起。

- 边缘停留 100 ms 后展开，离开窗口 600 ms 后收起。
- 点击“固定”保持展开。编辑笔记且窗口保持键盘焦点时不会自动收起。
- 托盘右键菜单可以退出。设置中可开启开机启动。
- 当前触边区域位于主显示器右侧，暂不支持拖到其他边缘。
- 默认宽度为 350；拖动窗口边缘或角落可调整宽高，松开后自动保存，下次展开或重启沿用。最小尺寸为 320 × 380，内容区域可滚动；窗口保持右侧停靠，屏幕空间不足时缩小到可用范围。拖动期间不会自动收起。

## 待办

支持新建、编辑、完成/取消完成、删除、分区、紧急程度、颜色、起止日期和独立提醒时间。

“未分类”是默认分区（旧版称“收件箱”）。点击“＋分区”可新增分类；在新建或编辑待办时选择所属分区，旧版待办会随默认分区一起迁移。

- 同时设置起止日期：区间内每一天都显示在“今日”，含首尾日期。
- 只设置截止日期：到期当天进入“今日”。
- 只设置起始日期：从该日持续显示，直到完成。
- 无日期：持续显示在“今日”。
- 超过截止日期仍未完成：保留在“今日”，标注逾期。
- 今日数量及进度条统计当前待办和今天完成的事项。
- 提醒通过 Windows 托盘通知发送，受系统通知设置影响。应用需运行；关机或退出期间错过的提醒在再次运行时补发。不会主动唤醒电脑。

## 笔记

标题、文件夹与富文本内容自动保存。支持粗体、斜体、下划线、删除线、项目符号、有序列表、缩进、撤销/重做，以及系统标准复制粘贴快捷键。

新建文件夹时使用 `工作/项目/草稿` 表示层级，自动建立父级；列表暂以完整路径显示。选择父文件夹会包含子文件夹的笔记，可在笔记编辑页更改所属文件夹。

## 外观与数据

默认系统微软雅黑 UI，可选择本机已安装字体；苹方只有安装后才会出现。透明度范围 55%–100%，当前调整的是整个窗口，包括文字。

实际数据保存在 `%LOCALAPPDATA%\SideNote\data.xml`，写入时通过临时文件替换，保留上一版 `data.xml.bak`。笔记以 RTF 存储在 XML 中，无网络同步。备份时退出应用后复制整个数据目录。

## 开发与验证

在此目录运行 `powershell -ExecutionPolicy Bypass -File build.ps1` 编译。

`SideNote.exe --self-test` 验证日期、完成过滤、中文持久化和备份恢复，结果写入 `test-result.txt`。

`SideNote.exe --preview --render` 使用隔离的 `qa-data` 数据目录，渲染 `preview.png` 后退出，不影响真实待办。

这是首个可试用版本：已完成编译与核心逻辑测试、主界面离屏渲染检查；真实触边体验、开机启动耗时及系统通知投递需要在用户桌面进一步验证。
